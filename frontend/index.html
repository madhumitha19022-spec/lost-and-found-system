About Campus Lost & Found

A simple, student-built system to reunite people with their belongings.

🎯 Our Mission

Losing something on a busy campus is stressful. Campus Lost & Found gives students and staff one central place to report lost items, log found ones, and search through active reports — instead of relying on scattered notice boards and group chats.

⚙️ How It's Built

The frontend is plain HTML, CSS and JavaScript talking to a Django REST Framework API backed by SQLite. Every report, edit, and deletion goes straight through the REST API in real time.

🔐 Good to Know

Please don't include sensitive personal information in item descriptions. Contact details you submit are shown publicly so others can reach you about a match.
